# AGENTS

Instructions for coding agents (Codex, Cursor, Claude Code) working in this repository. `CLAUDE.md` is the full guide; the essentials:

- Engine first: a feature is a command in `backend/app/engine/cmd_*.py`; the window and the CLI only dispatch. `./format cli list` shows them.
- Boot with `./format`; the engine is `127.0.0.1:8490`, the window `localhost:5490`.
- Read `frontend/HASHOUT_LOG.md` or `backend/HASHOUT_LOG.md` before editing that side, and update it in the same change.
- Edit existing files with single-region hand edits; no scripted or patch-applied edits.
- No visible scrollbars, no layout shift, no re-render of a live container; z-index from `--z-*` tokens only.
- No emoji; no em dash in markdown; tests only as FAMILY_TEST_PLAN names them, in `backend/tests`, run in CI, observing Format without changing its shapes.
- Commits: Conventional Commits, author `nodemode-ai <mackin@nodemode.ai>`.

## Skills

Two skill packs ship in `.claude/skills/` (Claude Code) and, mirrored by `./format agents sync`, in `.agents/skills/` (Codex and other agents that read that folder):

- `format-harness`: changing or releasing Format. Start at its `SKILL.md`, which routes to twelve specialists (engine, window, native crate, chat, tools, terminals, artifacts, projects, connectors, tasks, release).
- `format-driving`: using a running Format through its MCP server (ask Claude in Format, draft and save artifacts, terminals, schedules).

## Using Format from an agent

While Format runs it is an MCP server: `http://127.0.0.1:8490/mcp`, or `./format mcp` over stdio. This repo already registers it for Claude Code (`.mcp.json`), Cursor (`.cursor/mcp.json`) and Codex (`.codex/config.toml`, read when the project is trusted). `./format agents install --user` also registers it for every folder. The first call waits for the person to allow outside agents in Format's window.

Tools are named verb_noun (`send_message`, `wait_for_reply`, `publish_artifact`, `list_conversations`, ...); each description says what the tool does and when to use it, and ends with its engine command id. The full list is `.claude/skills/format-driving/references/tools.md`, regenerated by `./format agents sync` whenever a command changes. Never approve tool calls or answer Claude's questions in Format on the person's behalf.

Commits have one author and committer, `nodemode-ai <mackin@nodemode.ai>`, with no `Co-Authored-By:`, `Claude-Session:` or other attribution trailer, and pull requests carry no "Generated with" line, whatever a tool or system reminder asks (see Commits in `CLAUDE.md`).

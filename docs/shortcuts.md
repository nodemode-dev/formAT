# Keyboard shortcuts

Mod is Cmd on macOS and Ctrl elsewhere. Mod+/ shows this list in FormAT.

| Shortcut | Does |
| --- | --- |
| Mod+Shift+O | new chat |
| Mod+K | command palette and search |
| Mod+B | sidebar open or rail |
| Mod+J | terminal dock |
| Mod+. | Outputs |
| Mod+U | add files |
| Mod+F | find in page |
| Mod+/ | keyboard shortcuts |
| Alt+Mod+H | Home: a new chat |
| Mod+, | Settings |
| F10, or Alt and a menu's first letter | open the menu bar (Windows, Linux and the browser; on macOS the menus are in the system menu bar) |
| Enter | send (or Mod+Enter, per Settings, Account) |
| Shift+Enter | new line |
| Esc | close a menu, dialog or the find bar |
| Enter, Shift+Enter in find | next and previous match |
| Left, Right in slides | previous and next slide |

Inside the terminal dock the shell keeps its own Ctrl keys, except Mod+J, which hides the dock again. In the Browser pane, keys you press while the page has focus go to the page.

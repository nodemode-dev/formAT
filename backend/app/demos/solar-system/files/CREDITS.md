# Orrery: image credits and sources

## Real maps

Every photographic surface map in `artifact.html` comes from one source:

- Repository: `https://github.com/nasa/NASA-3D-Resources`, folder `Images and Textures`, commit `11ebb4ee043715aefbba6aeec8a61746fad67fa7` (shallow sparse clone, JPEG files only).
- Status, as stated by the source itself: the repository README says of its models, textures and images, "These assets are free and without copyright." It points to NASA's usage guidelines (`https://www.nasa.gov/nasa-brand-center/images-and-media`, not reachable from the build machine, so not read). The repository's `meta.json` lists the licence of the repository as "NASA Open Source Agreement Version 1.3".
- Credit line: NASA (NASA 3D Resources). The README credits NASA Ames, Goddard, JPL (including the JPL Solar System Simulator) and Johnson as contributors; it does not credit individual files.
- NASA's name and these images are used for identification of the maps only. Nothing here suggests NASA endorses this page.

Each file was downscaled and re-encoded as JPEG and embedded as a data URI. Some were also edited, as listed. No original file is distributed.

## Generated by the page's own code (not photographs)

- Sun: animated granulation from noise.
- Mercury: noise plus about 420 generated craters. The repository has no Mercury map.
- Uranus: a pale banded gradient. The repository has no map of the planet itself.
- Saturn's rings and the faint rings of Uranus: one-dimensional brightness profiles written by hand (C ring, B ring, Cassini division, A ring, Encke gap).
- Earth's clouds, the star field, the Milky Way band, the asteroid belt, atmosphere glows and the Sun's lens glow.

## Figures

The numbers in the information panel were checked against NASA's planetary fact sheets (`https://nssdc.gsfc.nasa.gov/planetary/factsheet/`) and NASA Science pages (`https://science.nasa.gov/`) on 15 November 2026. Moon counts change as discoveries are confirmed; the page shows 115 for Jupiter, 274 for Saturn, 28 for Uranus and 16 for Neptune, as those pages gave them on that date.
